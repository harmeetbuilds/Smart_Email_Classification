# Smart Email Classification

Smart Email Classification is an AI-powered email analysis system designed to automatically understand and classify incoming emails. The project combines Machine Learning, Natural Language Processing (NLP), and a web-based interface to analyze email content and provide useful classifications.

The system can:

📧 Detect Spam — identifies whether an email is spam or legitimate.
🧠 Classify Email Intent — determines the purpose of an email, such as a request, complaint, inquiry, or other categories.
⚡ Detect Email Priority — analyzes the email and determines its priority level.
💡 Generate Responses/Explanations — provides useful information based on the classification results.
🌐 Web Interface — provides an easy-to-use frontend for analyzing emails.
🔗 FastAPI Backend — provides APIs that connect the machine-learning models with the frontend.

The main goal of this project is to reduce manual email handling by automatically understanding email content and providing meaningful classification results.
